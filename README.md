## Setup

Create a virtual environment, activate it, and install the shared dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

On Windows, activate the environment with `.venv\Scripts\activate` instead.

Open the relevant notebook in Jupyter and run its cells in order. Dataset-specific paths and download instructions are documented in the README inside each assignment directory.
